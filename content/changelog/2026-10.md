Page reveals, one type scale, date picking, your own accent color and heading font, and a starter that installs everything, with 3 migrations.

## New

- [Reveal](/docs/reveal): 1 class on a page's container reveals it on load and on scroll, in landing and product presets with subtle steps. (#83)
- [Typography](/docs/typography): 5 text styles from one scale, plus `.typeset`, a markdown sheet whose to-dos draw like `CheckboxItem`. (#46)
- [Banner](/docs/banner): A status message in 5 statuses and 2 contrasts, with up to 3 actions and a dismiss that collapses its row. It sits inline, or fixed as a full-bleed bar. (#37, #41)
- [Calendar](/docs/calendar): A month grid for a day or a range, with one fluid hover across both months and a range band that follows the pointer. It marks booked days, shows ISO week numbers, and puts a `dayDetail` line under each date. (#82, #88)
- [DatePicker](/docs/date-picker): An outline or ghost trigger for a date, a range with presets, or a date and a time. Time slot lists show each duration, and the row keeps its width as you pick. (#82, #88)
- [Changelog](/changelog): One release per month, sorted into New, Breaking, and Updated, with a Copy migration prompt on every Breaking entry. (#70)
- [Starter](/): One `shadcn create` command scaffolds a Next.js app with every component installed and your Make them yours settings applied. The home page builds the command, accent color included. (#58, #86)
- **Make them yours**: A side panel sets the accent color from 17 presets or any hex, and headings in Geist Serif or any Google Fonts family. The starter brings both into your app. (#86, #95, #97)

## Breaking

- [Fluid Hover](/docs/fluid-hover): `useFluidHover` lights only the item under the pointer, and empty space puts the highlight out. Pass `nearest: true` to keep the nearest-item rule. (#95)

  ```diff
  - const hover = useFluidHover(containerRef);
  + const hover = useFluidHover(containerRef, { nearest: true });
  ```

- [Tabs](/docs/tabs): `Tabs` is the pill design `TabsSubtle` was, and the segmented control is gone. Install `tabs` and switch your imports to the new names. (#96)

  ```diff
  - import { TabsSubtle, TabsSubtleItem, TabsSubtlePanel } from "@/components/ui/tabs-subtle";
  + import { Tabs, TabsItem, TabsPanel } from "@/components/ui/tabs";
  ```

- **All components**: Components animate with the `motion` package instead of `framer-motion`. Import `MotionConfig` from `motion/react`, so your app shares their motion context. (#58)

  ```diff
  - import { MotionConfig } from "framer-motion";
  + import { MotionConfig } from "motion/react";
  ```

## Updated

- [Button](/docs/button): The `secondary` variant is a see-through tint, and Base UI projects pass `render` instead of `asChild`. (#37)
- [Dropdown](/docs/dropdown): `DropdownSub` opens a submenu whose row stays lit across the safe area. `Enter` and `Space` select the focused row on Base UI, and the search field is one stop in the arrow-key ring. (#52, #40)
- **Accent color**: `--fluid-accent` in `tokens` colors focus rings, the switch track, and text selection, with the blue as fallback. Badges take `color="accent"`. (#86, #95)
- **All components**: Installs bring every lib and token their code uses, and pass the React Compiler lint with 0 warnings in a fresh Next 16 app. (#47, #50, #51)
- **Base UI flavor**: Popups play their close animation on Base UI 1.9, which every Base UI install requires. Clicking a CheckboxGroup square toggles it once. (#57, #38)
