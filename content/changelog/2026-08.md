A 28px step for dense screens, a whole app shell in a single install, and 4 changes that need a migration.

## New

- [Sizes](/docs/sizes): 2 sizes for every control, a 36px default and a 28px compact, set per component with `size` or per region with `SizeProvider`. Text, icons and gaps step down with it. (#25)
- [Sidebar](/docs/sidebar): 3 layouts (sidebar, floating, inset), a rail that resizes or collapses on drag, a peek while collapsed, and a drawer on phones. `sidebar-app` installs a whole app shell built from it. (6967bee, 3e81e58, 88c9e6f)

## Breaking

- [Badge](/docs/badge): `badgeVariants` takes the size ladder's names, `default` and `compact`. The `size` prop still accepts the old ones, so only direct calls change. (#25)

  ```diff
  - <span className={badgeVariants({ size: "md" })}>
  + <span className={badgeVariants({ size: "default" })}>
  ```

- [Button](/docs/button): `buttonVariants` takes the size ladder's names, like `default` and `icon-compact`. The `size` prop still accepts the old ones, so only direct calls change. (#25)

  ```diff
  - <a className={buttonVariants({ size: "md" })}>
  + <a className={buttonVariants({ size: "default" })}>
  ```

- [Card](/docs/card): Dismissible cards hide their ✕ until hover or focus. Pass `dismissOnHover={false}` to keep it in view. (97e252f, a657ac1)

  ```diff
  - <Card dismissible onDismiss={close}>
  + <Card dismissible dismissOnHover={false} onDismiss={close}>
  ```

- [Slider](/docs/slider): A plain single-value `Slider` renders the pips design at the default size. Pass `size="compact"` to keep the dense design. (#25)

  ```diff
  - <Slider value={value} onChange={setValue} />
  + <Slider value={value} onChange={setValue} size="compact" />
  ```

## Updated

- [Motion](/docs/motion): Semibold labels hold their width within 0.4px, so long labels stop shrinking when selected. Height and width springs land without overshoot inside a scaled parent. (d975d45, #25, #29)
- [Accordion](/docs/accordion): Open items tint their row and panel as one block by default, and `highlight="trigger"` keeps the tint to the row, on hover only. A playground opens the page. (0c71b76, 79e4aa1, 24230ba)
- [Button](/docs/button): The default button grows from 32px to 36px to match inputs. A press shrinks it 1px on every side instead of scaling it. (#25, 08c5f95)
- [Card](/docs/card): Inline titles end in an ellipsis instead of clipping, and over a `CardImage` the ✕ sits on a blurred chip so it stays legible. (e7df73a, 8fe9810)
- [InputGroup](/docs/input-group): Inline fields like a toolbar search take `labelHidden`, which hides the label but keeps the field's accessible name. (#25)
- [InputMessage](/docs/input-message): `placeholderSuggestion` puts a prompt in the placeholder for `Tab` to fill, and `suggestions` lists several under the composer. The queued-messages stack installs on its own as `queued-stack`. (#26, 88c9e6f)
- [Tooltip](/docs/tooltip): Tooltips follow the pointer along one axis with `followCursor="x"` or `"y"`. (e693086, ce72954)
- **All components**: Installs ship the CSS they reference, with a new `tokens` item for hover, selected and focus-ring colors. Base UI and Radix installs of InputMessage, AskUserQuestions, ColorPicker and InputCopy get the current code and the Tooltip they import. (#27, 88c9e6f)
- **Playgrounds**: Get code turns a Sidebar, Card, InputMessage or AskUserQuestions playground setup into one install command, and a `?preset=` link reopens it. (16edf40, 02c27d4, 36aff7a)
