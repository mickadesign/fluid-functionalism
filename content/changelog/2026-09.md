Keyboard-first lists and commands, a skill that brings the library to your coding agent, and 3 changes that need a migration.

## New

- [Fluid Hover](/docs/fluid-hover): The highlight that follows your cursor to the nearest row gets its own page. It sits beside plain `:hover`, with the math, the cost per frame, and when to split a list. (4081b84, 6db793b, 6fc4b0a)
- [Skill](/docs/skill): An agent skill that reads your stack, measures the rendered page, suggests 2 to 5 upgrades, and installs them in the right flavor. Add it with `npx skills add mickadesign/fluid-functionalism`. (#34, 1add776)
- [CarouselDots](/docs/carousel-dots): Dots for a carousel, static or on `autoplay`, where the current dot is a pill that fills over each slide. A click between dots lands on the lit one. (#34, #35)
- [Combobox](/docs/combobox): A text field that filters a list as you type, for a single pick or many as chips, in both flavors. The first row stays highlighted so Enter always has a target, and `onCreate` adds a row that creates what you typed. (ae99a4f, 151f7af, f6e70ca)
- [CommandMenu](/docs/command-menu): A dialog on `⌘K` that filters actions as you type and runs the highlighted one on `Enter`. It groups rows, shows shortcut caps, and takes tabs. (0fd6845)

## Breaking

- [Fluid Hover](/docs/fluid-hover): The hook and its registry item take the fluid hover name. A click between rows lands on the highlighted row, and `gapClick: false` keeps the gaps inert. (ef767f3, 6db793b)

  ```diff
  - import { useProximityHover, useRegisterProximityItem } from "@/hooks/use-proximity-hover";
  + import { useFluidHover, useRegisterFluidHoverItem } from "@/hooks/use-fluid-hover";
  - const hover = useProximityHover(containerRef);
  + const hover = useFluidHover(containerRef, { gapClick: false });
  ```

- [Card](/docs/card): `fluidHover` replaces `proximityHover` on `CardGroup`. (ef767f3)

  ```diff
  - <CardGroup proximityHover={false}>
  + <CardGroup fluidHover={false}>
  ```

- **All components**: Components default to 8px rounded corners instead of 20px pills. Set `defaultShape="pill"` on `ShapeProvider` to keep pills. (4d4fe38)

  ```diff
  - {children}
  + <ShapeProvider defaultShape="pill">{children}</ShapeProvider>
  ```

## Updated

- [Fluid Hover](/docs/fluid-hover): Rows that share a highlight stack with no gap, so no spot in a list is dead. Under reduced motion it fades in place instead of traveling, and `FluidHoverHighlight` installs with the hook for your own lists. (74599e2, 1eb4a75)
- [Dialog](/docs/dialog): An `xl` size, 880px wide, fits a settings dialog with a sidebar, and the `dialog-sidebar` block installs one. Both flavors take `showCloseButton`, `position="top"`, and your own trigger element. (ae99a4f, 0fd6845)
- [Dropdown](/docs/dropdown): `DropdownSearch` puts a filter field at the top of the popup, and `checkedIndices` turns rows into checkboxes whose touching picks share one background. Long menus scroll with edge fades, and the popup slides in from the side it opens on. (ae99a4f)
- [Select](/docs/select): Long lists scroll with edge fades, and a popup opened by mouse shows no focus ring on its first row. Under a pill shape the popup keeps rounded corners, like Dropdown. (ae99a4f, 0fd6845)
- [Sidebar](/docs/sidebar): The hover highlight fades in on the row you point at, and disabled rows are skipped by hover, arrow keys, and clicks. Pass `focusRing={false}` to `SidebarMenu` and keyboard focus moves only the hover background. (ae99a4f, 6fc4b0a, ec054bb)
- **Copy prompt**: Every docs page and playground trades its install command for a Copy prompt button, a brief your coding agent follows. The command carries `--overwrite`, so same-named shadcn files don't stall the install. (653eaf3, e07409c, 4d4fe38)
- **Images**: Card images, ThinkingSteps screenshots, and file attachments carry a 1px inset outline, so a white image keeps its edge on a white page. Attachments round their corners to match the surface around them. (#34)
